# SyncPlay Support

## Before opening an issue

Please make sure you are using the [latest SyncPlay release](https://github.com/prateek-upreti/syncplay-in/releases/latest).

For connection or timing problems, please tell us:

- Windows version
- SyncPlay version (Admin → System)
- Speaker and phone models
- How each one is connected: Bluetooth, Google Cast (Wi-Fi) or phone browser
- Whether the PC, Cast speakers and phones are on the same Wi-Fi network
- Steps that reproduce the problem

## Bug reports

[Open a GitHub issue](https://github.com/prateek-upreti/syncplay-in/issues/new/choose) with as much detail as possible. Screenshots and error messages help. Remove anything private (names, email addresses, IP addresses) before posting.

## Feature requests

Describe the problem you are trying to solve, what you would like SyncPlay to do, and how you would use it.

support@syncplay.in

## Security issues

Please do not publish security details in a public issue. See [SECURITY.md](SECURITY.md).
