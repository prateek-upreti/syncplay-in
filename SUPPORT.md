# SyncPlay Support

## Before opening an issue

Please make sure you are using the latest SyncPlay release.

For connection or synchronization problems, confirm:

- Windows version
- SyncPlay version
- Speaker/device models
- Bluetooth or Wi-Fi connection type
- Whether all devices are on the same local network when required
- Steps that reproduce the problem

## Bug reports

Open a GitHub issue and provide as much detail as possible. Screenshots, error messages, and relevant logs are helpful.

## Feature requests

Describe the problem you are trying to solve, the desired behavior, and an example of how you would use the feature.

## Security issues

Please do not publish sensitive security details in a public issue. Contact the project maintainer through the official SyncPlay website first.
